After you [sign up and activate](/getting-started/sign-up-and-activate-your-account), you can find these values in your setup email and dashboard.

## Required settings

| Setting | Value |
| --- | --- |
| SMTP Server (dedicated IP) | Your relay hostname from the setup email (e.g. `relayxx.mysmtp.com`) |
| SMTP Server (shared IP, DK only) | `mail.mysmtp.com` |
| Port | 587 (STARTTLS, primary), 2525, or 25 |
| Encryption | STARTTLS (port 587) or implicit TLS (port 465), TLS 1.2 or 1.3 only |
| Username | Your mySMTP SMTP username |
| Password | Your mySMTP SMTP password |

<Note>
  Use the exact relay hostname from your setup email. `relayxx.mysmtp.com` is only an example. Shared IP plans use `mail.mysmtp.com` and are only available in Denmark.
</Note>

## Find your credentials

<Steps>
  <Step title="Open your setup email">
    After activation, mySMTP sends a setup email with your relay hostname, SMTP username, and password. Keep this email available during setup.
  </Step>
  <Step title="Log in to the dashboard">
    Go to [app.mysmtp.com](https://app.mysmtp.com) and sign in as the account owner. You can create and manage SMTP users under **SMTP Users**.
  </Step>
  <Step title="Create an SMTP user if needed">
    If you are using a dedicated IP server, create a new SMTP user in the dashboard for each integration or team member. Each user has its own username and password.
  </Step>
</Steps>

## Enter credentials in your application

Use the values from the table above in your email client or application:

- **Email clients:** add mySMTP as an outgoing (SMTP) server. See guides for [Thunderbird](/email-configuration/email-clients/thunderbird), [Outlook 2025](/email-configuration/email-clients/outlook-2025), [Mac Mail](/email-configuration/email-clients/mac-mail-2025), or [Android Mail](/email-configuration/email-clients/android-mail).
- **Web applications:** set the SMTP host, port, and credentials in your application settings. See guides for [MailWizz](/email-configuration/web-applications/mailwizz), [Mumara](/email-configuration/web-applications/mumara), [Interspire](/email-configuration/web-applications/interspire), and others.
- **Custom applications:** use the values with your language or framework's mailer library (for example, `symfony/mailer` with the `MAILER_DSN` environment variable in Symfony).

## Test your credentials

Send a test email to be sure everything works:

1. In your application, send a message to an address you control, such as a Gmail or Outlook inbox.
2. Check that the message arrives and is not marked as spam.
3. Use [test.smtp.ai](https://test.smtp.ai) to verify authentication, encryption, and blacklist status.

## Troubleshooting

| Problem | Cause and fix |
| --- | --- |
| Authentication failed | Double-check the SMTP username and password. If you use a dedicated IP, confirm the credentials match the SMTP user in your dashboard. |
| Connection timed out | Your network or ISP may block the port you are using. Try port **587** with STARTTLS, or port **2525** as an alternative. |
| Relay access denied | Make sure your sender domain is authenticated for your mySMTP account. See [DNS settings quick explainer](/getting-started/dns-settings-quick-explainer). |

For more errors and responses, see [Common SMTP errors](/troubleshooting/common-smtp-errors).
