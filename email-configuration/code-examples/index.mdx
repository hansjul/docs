You can integrate mySMTP into any application using standard SMTP libraries. Each example below uses secure authentication and TLS encryption.

## Connection settings

| Setting | Value |
| --- | --- |
| Hostname | `relayxx.mysmtp.com` (your real hostname is in your setup email) |
| Shared IP hostname (DK only) | `mail.mysmtp.com` |
| Port (recommended) | `587` with STARTTLS |
| Alternative ports | `465` (implicit TLS), `2525` (STARTTLS fallback) |
| Authentication | SMTP username and password |

<Warning>
  Never hardcode SMTP passwords in source code. Load credentials from environment variables, secrets managers, or encrypted configuration files.
</Warning>
