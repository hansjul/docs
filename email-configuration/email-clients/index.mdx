All setups share the same basic SMTP settings and authentication method. Pick your platform below and follow the guide.

## Basic SMTP settings

| Setting | Value |
| --- | --- |
| Server | `relayxx.mysmtp.com` (from your setup email) |
| Server (shared IP, DK only) | `mail.mysmtp.com` |
| Port | **587** (primary), 2525 or 25 |
| Encryption | **STARTTLS** |
| Authentication | Normal password / Login |
| Username | Your mySMTP SMTP username |
| Password | Your mySMTP SMTP password |

<Note>
  Shared IP plans are only available to customers in Denmark.
</Note>
