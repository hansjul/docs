Each article includes the correct server settings, ports, and authentication steps for shared IP and dedicated IP accounts.

## Quick reference

| Setting | Value |
| --- | --- |
| Server (dedicated IP) | Your relay hostname from the setup email (e.g. `relayxx.mysmtp.com`) |
| Server (shared IP, DK only) | `mail.mysmtp.com` |
| Port | **587** (primary), 2525 or 25 |
| Encryption | **STARTTLS** (or TLS) |
| Authentication | Normal password with your SMTP username |

<Note>
  Use the server hostname from your mySMTP setup email. Dedicated IP customers receive a specific relay hostname such as `relayxx.mysmtp.com`. Shared IP plans use `mail.mysmtp.com` and are only available in Denmark.
</Note>
