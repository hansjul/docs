This section covers how to connect mySMTP to popular CMS platforms and web frameworks. Each guide includes the correct SMTP settings, step-by-step configuration, and troubleshooting tips.

## Common SMTP settings

| Setting | Value |
| --- | --- |
| Host | `relayxx.mysmtp.com` (from your setup email) |
| Host (shared IP, DK only) | `mail.mysmtp.com` |
| Port | `587` |
| Encryption | TLS / STARTTLS |
| Username | Your mySMTP SMTP username |
| Password | Your mySMTP SMTP password |

<Note>
  Shared IP plans are only available to customers in Denmark. For plans and IPs, see [Shared IPs or dedicated IPs](/getting-started/shared-ips-or-dedicated).
</Note>
