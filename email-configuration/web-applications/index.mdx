You need your mySMTP SMTP credentials and access to your platform's admin panel or server files.

## SMTP settings

Use these values unless your platform requires something specific. Dedicated IP users should use the hostname from their setup email.

| Setting | Value |
| --- | --- |
| Server | `relayxx.mysmtp.com` (from your setup email) |
| Server (shared IP, DK only) | `mail.mysmtp.com` |
| Port | `587` |
| Encryption | `STARTTLS` (TLS) |
| Authentication | Normal password / Login |
| Username | Your mySMTP SMTP username |
| Password | Your mySMTP password |

<Note>
  Some platforms label port 465 as "SSL". mySMTP only supports TLS 1.2 and 1.3 and recommends port 587 with STARTTLS. If your host blocks 587, try port 2525.
</Note>

<Note>
  Shared IP plans are only available to customers in Denmark.
</Note>

<Tip>
  Validate your DNS records before sending with the [mySMTP Deliverability Toolbox](https://toolbox.smtp.ai/).
</Tip>

## Platform quick guides

<Tabs>
  <Tab title="WordPress">
    Use the WP Mail SMTP plugin for the most reliable setup.

    <Steps>
      <Step title="Install the plugin">
        Go to **Plugins → Add New**, search for **WP Mail SMTP**, and install it.
      </Step>
      <Step title="Choose the mailer">
        Go to **WP Mail SMTP → Settings**. Under **Mailer**, select **Other SMTP**.
      </Step>
      <Step title="Enter mySMTP credentials">
        - SMTP Host: `relayxx.mysmtp.com` (from your setup email)
        - Encryption: TLS
        - Port: `587`
        - Username and Password: your mySMTP credentials
      </Step>
      <Step title="Save and test">
        Save changes and click **Send Test** to confirm delivery.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Magento">
    <Steps>
      <Step title="Open mail settings">
        In the Magento Admin, go to **Stores → Configuration → Advanced → System**.
      </Step>
      <Step title="Set the SMTP host">
        Expand **Mail Sending Settings** and enter:

        - Host: `relayxx.mysmtp.com` (from your setup email)
        - Port: `587`
        - Authentication: **Login**
        - Username and Password: your mySMTP credentials
      </Step>
      <Step title="Save and test">
        Save the settings and send a test email from the store.
      </Step>
    </Steps>
  </Tab>
  <Tab title="WooCommerce">
    WooCommerce uses the WordPress mailer. Follow the **WordPress** tab above with WP Mail SMTP, then verify that WooCommerce emails use the correct sender address in **WooCommerce → Settings → Emails**.
  </Tab>
  <Tab title="PrestaShop">
    <Steps>
      <Step title="Open email settings">
        Go to **Advanced Parameters → Email**.
      </Step>
      <Step title="Use your own SMTP">
        Select **Set my own SMTP parameters**.
      </Step>
      <Step title="Enter credentials">
        Fill in the host (`relayxx.mysmtp.com` from your setup email), port 587, username, password, and TLS encryption, then save.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Drupal">
    <Steps>
      <Step title="Install the module">
        Install the **SMTP Authentication Support** module.
      </Step>
      <Step title="Configure SMTP">
        Go to **Configuration → SMTP Authentication** and enter your mySMTP host (`relayxx.mysmtp.com` from your setup email), port 587, username, password, and TLS.
      </Step>
      <Step title="Save and send a test">
        Save and use the module's test option to verify delivery.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Joomla">
    <Steps>
      <Step title="Open Global Configuration">
        Go to **System → Global Configuration → Server**.
      </Step>
      <Step title="Set the mailer to SMTP">
        Set **Mailer** to **SMTP** and fill in:

        - Host: `relayxx.mysmtp.com` (from your setup email)
        - Port: `587`
        - Security: STARTTLS
        - Authentication: Yes
        - Username and Password: your mySMTP credentials
      </Step>
      <Step title="Save">
        Save the configuration and send a test message.
      </Step>
    </Steps>
  </Tab>
  <Tab title="OpenCart">
    <Steps>
      <Step title="Open mail settings">
        Go to **Settings → Mail**.
      </Step>
      <Step title="Choose SMTP">
        Set **Mail Engine** to **SMTP** and enter your mySMTP host (`relayxx.mysmtp.com` from your setup email), port 587, username, password, and TLS.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Laravel">
    Update your `.env` file:

    ```bash
    MAIL_MAILER=smtp
    MAIL_HOST=relayxx.mysmtp.com
    MAIL_PORT=587
    MAIL_USERNAME=your_username
    MAIL_PASSWORD=your_password
    MAIL_ENCRYPTION=tls
    MAIL_FROM_ADDRESS=you@yourdomain.com
    MAIL_FROM_NAME="Your App"
    ```

    Then clear the config cache:

    ```bash
    php artisan config:clear
    ```
  </Tab>
  <Tab title="Symfony">
    Update your `.env` file:

    ```bash
    MAILER_DSN="smtp://your_username:your_password@relayxx.mysmtp.com:587"
    ```

    Test the connection:

    ```bash
    php bin/console mailer:test you@yourdomain.com
    ```
  </Tab>
  <Tab title="Django">
    Update `settings.py`:

    ```python
    EMAIL_BACKEND = "django.core.mail.backends.smtp.EmailBackend"
    EMAIL_HOST = "relayxx.mysmtp.com"
    EMAIL_PORT = 587
    EMAIL_USE_TLS = True
    EMAIL_HOST_USER = "your_username"
    EMAIL_HOST_PASSWORD = "your_password"
    DEFAULT_FROM_EMAIL = "you@yourdomain.com"
    ```

    Restart the application.
  </Tab>
  <Tab title="ASP.NET Core">
    Add settings to `appsettings.json`:

    ```json
    {
      "SmtpSettings": {
        "Server": "relayxx.mysmtp.com",
        "Port": 587,
        "Username": "your_username",
        "Password": "your_password",
        "UseStartTls": true
      }
    }
    ```

    Inject the settings into your mail service and send via `System.Net.Mail.SmtpClient` or `MailKit`.
  </Tab>
  <Tab title="Ghost">
    Update `config.production.json`:

    ```json
    "mail": {
      "transport": "SMTP",
      "options": {
        "host": "relayxx.mysmtp.com",
        "port": 587,
        "auth": {
          "user": "your_username",
          "pass": "your_password"
        }
      }
    }
    ```

    Restart Ghost.
  </Tab>
</Tabs>

## Quick fixes

<AccordionGroup>
  <Accordion title="Port blocked">
    If 587 is blocked by your host or ISP, try port 2525.
  </Accordion>

  <Accordion title="Authentication failed">
    Confirm your username and password match your mySMTP account, and that TLS/STARTTLS is selected.
  </Accordion>

  <Accordion title="Relay denied">
    Make sure the sender domain is authenticated for your mySMTP account. See [DNS settings quick explainer](/getting-started/dns-settings-quick-explainer).
  </Accordion>

  <Accordion title="Emails going to spam">
    Verify SPF, DKIM, and DMARC for your domain. See [SPF, DKIM, DMARC and BIMI explained](/deliverability/spf-dkim-dmarc-and-bimi-explained) and test with the [mySMTP Deliverability Toolbox](https://toolbox.smtp.ai/).
  </Accordion>
</AccordionGroup>

For platform-specific errors, check the dedicated guide above or [Common SMTP errors](/troubleshooting/common-smtp-errors).
