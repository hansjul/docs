You need your mySMTP SMTP credentials, including the relay host from your setup email.

## SMTP settings

| Setting | Value |
| --- | --- |
| Server | `relayxx.mysmtp.com` (from your setup email) |
| Server (shared IP, DK only) | `mail.mysmtp.com` |
| Port | `587` |
| Use Secure Connection | Yes (select **TLS** or STARTTLS if shown) |
| Authentication | Yes |
| Login (username) | Your full mySMTP username |
| Password | Your mySMTP password |
| Sender Email | e.g. `you@yourdomain.com` |

<Note>
  Shared IP plans are only available to customers in Denmark.
</Note>

## Configure Atomic Mail Sender

<Steps>
  <Step title="Open SMTP settings">
    Launch **Atomic Mail Sender**. Go to the top menu and click **Settings → Common Settings**. In the left-hand menu, choose **SMTP**.
  </Step>
  <Step title="Enter mySMTP credentials">
    Fill in the SMTP fields with the values from the table above.
  </Step>
  <Step title="Test the connection">
    Click **Test Connection** or **Send Test Email** (depending on version). Check that the test message is sent and received successfully.
  </Step>
</Steps>

<Warning>
  Choose **TLS (STARTTLS)** on port 587. Do not use port 465.
</Warning>

<Tip>
  Before sending to a large list, clean it with the [Email List Analyzer](https://toolbox.smtp.ai/) and check your template with the [Email Template Verifier](https://toolbox.smtp.ai/) in the mySMTP Deliverability Toolbox.
</Tip>

## Troubleshooting

- **Connection fails:** confirm the host matches your setup email, the port is 587, and TLS is selected. If your network blocks 587, try port 2525.
- **Authentication error:** re-enter your mySMTP username and password. Make sure there are no extra spaces.
- **Emails going to spam:** verify SPF, DKIM, and DMARC for your sending domain. See [DNS settings quick explainer](/getting-started/dns-settings-quick-explainer) and [SPF, DKIM, DMARC, and BIMI explained](/deliverability/spf-dkim-dmarc-and-bimi-explained).

For more error codes, see [Common SMTP errors](/troubleshooting/common-smtp-errors).
