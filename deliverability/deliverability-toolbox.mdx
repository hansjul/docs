## Which tool to use when

| Situation | Start with |
| --- | --- |
| Setting up a new sending domain | [One-Click SPF / DKIM / DMARC Checker](https://toolbox.smtp.ai/), then the DMARC Wizard |
| Starting on a new dedicated IP | PTR / rDNS Checker, then the Warmup Plan Generator |
| Emails landing in spam | Sender Readiness Checklist and Email Header Analyzer |
| A message bounced | Bounce Code Decoder |
| Sending was suddenly blocked | Blacklist Checker |
| Before importing a new list | Email List Analyzer |
