## Hvordan vi indsamler og behandler data

Vi indsamler kun information, der er nødvendig for e-mail levering, herunder:

- E-mail adresser og SMTP legitimationsoplysninger
- Brugslogs og leveringsstatus data

Vi deler ikke dine data med tredjeparter til markedsføring eller reklame. Al behandling er baseret på legitim interesse og samtykke principper.

## Hvor og hvordan vi opbevarer data

| Foranstaltning | Detalje |
| --- | --- |
| Placering | Sikre, GDPR-overholdende servere i EU. SMTP infrastrukturen bruger ingen eksterne US cloud services ([hvad dette betyder for CLOUD Acten](/da/getting-started/introduction-to-the-service#what-is-the-us-cloud-act)) |
| Kryptering | TLS 1.2+ for data under transport |
| Adgangskontrol | Streng, rollebaseret adgang kun for autoriseret personale |

## Dataopbevaring og sletning

Vi opbevarer data kun så længe som nødvendigt for servicelevering og juridiske forpligtelser. Du kan anmode om sletning til enhver tid under din ret til sletning (artikel 17). Kontakt [support@mysmtp.com](mailto:support@mysmtp.com), og vi bekræfter gennemførelsen inden for 30 dage.

## Dine GDPR rettigheder

| Ret | Hvad det betyder |
| --- | --- |
| Adgang | Anmod om detaljer om de data, vi opbevarer om dig |
| Rettelse | Opdater forkerte eller ufuldstændige oplysninger |
| Sletning | Anmod om permanent sletning af dine persondata |
| Portabilitet | Modtag en kopi af dine data i et struktureret format |

## Sikkerhedsforanstaltninger

- To-faktor autentificering (2FA) til kontosikkerhed
- Regelmæssige sikkerhedsrevisioner og sårbarhedsvurderinger
- Logning og overvågning for at opdage uautoriseret adgang

<Tip>
  Hvis du har brug for at analysere headers eller autentificeringsdata til GDPR-relaterede kontroller, prøv [mySMTP Email Header Analyzer](https://toolbox.smtp.ai/). Den kører udelukkende i din browser, så dine data ikke sendes til mySMTP servere.
</Tip>

For GDPR-relaterede henvendelser eller dataanmodninger, kontakt os på [support@mysmtp.com](mailto:support@mysmtp.com).

Hvis du har brug for en Databehandlingsaftale til GDPR artikel 28 compliance, se [Databehandlingsaftale](/da/security-compliance/data-processing-agreement).
