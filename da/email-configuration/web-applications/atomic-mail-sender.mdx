Du skal bruge dine mySMTP SMTP-legitimationsoplysninger, inklusive relay-værten fra din opsætningsmail.

## SMTP-indstillinger

| Indstilling | Værdi |
| --- | --- |
| Server | `relayxx.mysmtp.com` (fra din opsætningsmail) |
| Server (delt IP, kun DK) | `mail.mysmtp.com` |
| Port | `587` |
| Use Secure Connection | Ja (vælg **TLS** eller STARTTLS, hvis vist) |
| Authentication | Ja |
| Login (brugernavn) | Dit fulde mySMTP-brugernavn |
| Password | Dit mySMTP-adgangskode |
| Sender Email | f.eks. `you@yourdomain.com` |

<Note>
  Delte IP-planer er kun tilgængelige for kunder i Danmark.
</Note>

## Konfigurer Atomic Mail Sender

<Steps>
  <Step title="Åbn SMTP-indstillinger">
    Start **Atomic Mail Sender**. Gå til topmenuen, og klik på **Settings → Common Settings**. I menuen til venstre skal du vælge **SMTP**.
  </Step>
  <Step title="Indtast mySMTP-legitimationsoplysninger">
    Udfyld SMTP-felterne med værdierne fra tabellen ovenfor.
  </Step>
  <Step title="Test forbindelsen">
    Klik på **Test Connection** eller **Send Test Email** (afhængigt af versionen). Tjek, at testbeskeden sendes og modtages succesfuldt.
  </Step>
</Steps>

<Warning>
  Vælg **TLS (STARTTLS)** på port 587. Brug ikke port 465.
</Warning>

<Tip>
  Før du sender til en stor liste, skal du rense den med [Email List Analyzer](https://toolbox.smtp.ai/) og tjekke din skabelon med [Email Template Verifier](https://toolbox.smtp.ai/) i mySMTP Deliverability Toolbox.
</Tip>

## Fejlfinding

- **Forbindelse mislykkedes:** bekræft, at værten matcher din opsætningsmail, at porten er 587, og at TLS er valgt. Hvis dit netværk blokerer 587, kan du prøve port 2525.
- **Godkendelsesfejl:** genindtast dit mySMTP-brugernavn og din adgangskode. Sørg for, at der ikke er ekstra mellemrum.
- **E-mails ender i spam:** verificer SPF, DKIM og DMARC for dit afsenderdomæne. Se [DNS-indstillinger, hurtig forklaring](/da/getting-started/dns-settings-quick-explainer) og [SPF, DKIM, DMARC og BIMI forklaret](/da/deliverability/spf-dkim-dmarc-and-bimi-explained).

For flere fejlkoder, se [Almindelige SMTP-fejl](/da/troubleshooting/common-smtp-errors).
