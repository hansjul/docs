Opsæt Outlook til at sende mails via mySMTP ved at opdatere den udgående (SMTP) server på din eksisterende konto. Indstillingerne for indgående mails via mySMTP ved at opdatere den udgående (SMTP) server på din eksisterende konto. Indstillingerne for indgående mail forbliver uændrede.

## SMTP-indstillinger

| Indstilling | Værdi |
| --- | --- |
| Udgående mailserver | `relayxx.mysmtp.com` (fra din opsætningsmail) |
| Udgående mailserver (delt IP, kun DK) | `mail.mysmtp.com` |
| Port | **587** |
| Kryptering | **STARTTLS** |
| GodkendelseGodkendelse | Påkrævet |
| Brugernavn / adgangskode | Dit mySMTP SMTP-brugernavn og -adgangskode |

<Note>
  Delt IP-abonnementabonnementer er kun tilgængelige for kunder i Danmark.
</Note>

## Fejlfinding

- **Testen fejler på den udgående server:** Kontroller,Kontroller, at brugernavnet og adgangskoden er dine mySMTP SMTP-legitimationsoplysninger, ikke dit mailbox-login.
- **Forbindelsen udløber:** Dit netværk kan blokereDit netværk kan blokere port 587. Prøv port **2525**.
- **Relay nægtet:** Sørg for, at afsenderadressen bruger et domæne, der er godkendt for din mySMTP-konto. Se [DNS-indstillinger,Sørg for, at afsenderadressen bruger et domæne, der er godkendt for din mySMTP-konto. Se DNS-indstillinger, hurtig forklaring](/da/getting-started/dns-settings-quick-explainer).
