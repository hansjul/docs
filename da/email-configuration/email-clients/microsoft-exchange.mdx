Exchange Server 2019 dirigerer udgående mail via en send connector. Trinnene nedenfor konfigurerer mySMTP som smart host med TLS på port 587.

## Før du starter

Ha' disse oplysninger fra din mySMTP-opsætningsmail klar:

| Indstilling | Værdi |
| --- | --- |
| Server | `relayxx.mysmtp.com` (fra din opsætningsmail) |
| Server (delt IP, kun DK) | `mail.mysmtp.com` |
| Port | **587** |
| Kryptering | **TLS (STARTTLS)** |
| Brugernavn | Dit mySMTP-brugernavn |
| Adgangskode | Dit mySMTP-adgangskode |

<Note>
  Delt IP-abonnementer er kun tilgængelige for kunder i Danmark.
</Note>

## Opsæt send connectoren

<Tabs>
  <Tab title="Exchange Admin Center">
    <Steps>
      <Step title="Åbn Exchange Admin Center">
        Åbn din browser, gå til `https://<DinExchangeServer>/ecp` og log ind med admin-legitimationsoplysninger.
      </Step>
      <Step title="Opret en ny send connector">
        1. Gå til **Mail Flow** > **Send Connectors**.
        2. Klik på ikonet **\+ (plus)**.
        3. Navngiv den `mySMTP` (eller lignende), og indstil **Type** til **Internet**.
        4. Klik på **Næste**.
      </Step>
      <Step title="Konfigurer smart host">
        1. På skærmen **Network settings** skal du vælge **Route mail through smart hosts**.
        2. Klik på **\+ Tilføj** og indtast dit relay-hostnavn (f.eks. `relayxx.mysmtp.com`).
        3. Klik på **Næste**.
      </Step>
      <Step title="Opsæt godkendelse">
        1. På skærmen **Smart host authentication** skal du vælge **Basic Authentication**.
        2. Marker **Offer basic authentication only after starting TLS**.
        3. Indtast dit mySMTP **brugernavn** og **adgangskode**.
        4. Klik på **Næste**.
      </Step>
      <Step title="Tilføj address space">
        1. Klik på **\+ Tilføj**.
        2. Indtast `*` som **Full Qualified Domain Name (FQDN)** og behold **Cost** på `1`.
        3. Klik på **Gem**, og derefter **Næste**.

        Address space `*` sender mail til alle eksterne domæner via mySMTP.
      </Step>
      <Step title="Vælg source server">
        Klik på **\+ Tilføj**, vælg din Exchange-server (f.eks. `EXCH01`), og klik på **Afslut**.
      </Step>
      <Step title="Sæt porten til 587">
        EAC opretter altid connectorer på port 25 og har intet felt til at ændre det. Åbn **Exchange Management Shell** og kør:

        ```powershell
        Set-SendConnector -Identity "mySMTP" -Port 587 -RequireTLS $true
        ```
      </Step>
    </Steps>
  </Tab>
  <Tab title="Exchange Management Shell">
    Kør dette i **Exchange Management Shell**. Erstat relay-hostnavnet og servernavnet med dine egne. Du bliver bedt om dit mySMTP-brugernavn og -adgangskode.

    ```powershell
    New-SendConnector -Name "mySMTP" `
      -Usage Internet `
      -AddressSpaces "*" `
      -DNSRoutingEnabled $false `
      -SmartHosts "relayxx.mysmtp.com" `
      -Port 587 `
      -RequireTLS $true `
      -SmartHostAuthMechanism BasicAuthRequireTLS `
      -AuthenticationCredential (Get-Credential) `
      -SourceTransportServers "EXCH01"
    ```
  </Tab>
</Tabs>

<Warning>
  Hvis du allerede har en anden send connector med address space `*`, kan Exchange fortsætte med at bruge den. Deaktiver den gamle connector, eller giv mySMTP-connectoren en lavere cost.
</Warning>

## Test forbindelsen

1. Send en testmail fra en brugermailbox (f.eks. ved hjælp af Outlook eller OWA) til en ekstern adresse, som f.eks. en Gmail-konto eller din egen.
2. Bekræft, at beskeden ankommer. I de modtagne beskedheaders bør du se, at den er passeret gennem din mySMTP-relay.
3. Hvis beskeden ikke ankommer, skal du tjekke køen i Exchange Management Shell:
   ```powershell
   Get-Queue | Where-Object { $_.NextHopDomain -like "*mysmtp*" } | Format-List NextHopDomain,Status,LastError
   ```

## Fejlfinding

<AccordionGroup>
  <Accordion title="Beskeder bliver i køen med en forbindelsesfejl">
    Kontroller, at udgående trafik på port **587** er tilladt af din firewall, og at connector-porten er sat til 587 (`Get-SendConnector "mySMTP" | Format-List Port`).
  </Accordion>

  <Accordion title="Godkendelse fejlede (535)">
    Genindtast dit mySMTP-brugernavn og -adgangskode på connectoren, og bekræft at **Offer basic authentication only after starting TLS** er aktiveret.
  </Accordion>

  <Accordion title="Relay-adgang nægtet">
    Sørg for, at afsenderadressen bruger et domæne, der er godkendt for din mySMTP-konto. Se [DNS-indstillinger, hurtig forklaring](/da/getting-started/dns-settings-quick-explainer).
  </Accordion>
</AccordionGroup>

For flere fejlkoder, se [Almindelige SMTP-fejl](/da/troubleshooting/common-smtp-errors).
