Alle opsætninger bruger de samme grundlæggende SMTP-indstillinger og autentificeringsmetode. Vælg din platform nedenfor og følg guiden.

## Grundlæggende SMTP-indstillinger

| Indstilling | Værdi |
| --- | --- |
| Server | `relayxx.mysmtp.com` (fra din opsætningsmail) |
| Server (delt IP, kun DK) | `mail.mysmtp.com` |
| Port | **587** (primær), 2525 eller 25 |
| Kryptering | **STARTTLS** |
| Godkendelse | Normal adgangskode / Login |
| Brugernavn | Dit mySMTP SMTP-brugernavn |
| Adgangskode | Dit mySMTP SMTP-adgangskode |

<Note>
  Delt IP-abonnementer er kun tilgængelige for kunder i Danmark.
</Note>
