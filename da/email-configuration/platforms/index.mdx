Dette afsnit beskriver, hvordan du forbinder mySMTP til populare CMS-platforme og web-frameworks. Hver vejledning indeholder de korrekte SMTP-indstillinger, trinvis konfiguration og fejlfindingstips.

## Faelles SMTP-indstillinger

| Indstilling | Vaerdi |
| --- | --- |
| Host | `relayxx.mysmtp.com` (fra din opsaetningsmail) |
| Host (shared IP, kun DK) | `mail.mysmtp.com` |
| Port | `587` |
| Kryptering | TLS / STARTTLS |
| Brugernavn | Dit mySMTP SMTP-brugernavn |
| Adgangskode | Dit mySMTP SMTP-adgangskode |

<Note>
  Shared IP-planer er kun tilgaengelige for kunder i Danmark. Se planer og IPs under [Shared IPs eller dedikerede IPs](/da/getting-started/shared-ips-or-dedicated).
</Note>

## Brug for hjaelp?

Hvis din platform ikke er listet, kan du som regel forbinde ethvert system, der understotter SMTP, ved at indtaste ovenstående indstillinger. Kontakt [support@mysmtp.com](mailto:support@mysmtp.com) for providerspecifikke trin.
