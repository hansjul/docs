Hver artikel indeholder de korrekte serverindstillinger, porte og godkendelsestrin til shared IP- og dedikeret IP-konti.

## Hurtigreference

| Indstilling | Vaerdi |
| --- | --- |
| Server (dedikeret IP) | Dit relay-hostname fra opsaetningsmailen (fx `relayxx.mysmtp.com`) |
| Server (shared IP, kun DK) | `mail.mysmtp.com` |
| Port | **587** (primaer), 2525 eller 25 |
| Kryptering | **STARTTLS** (eller TLS) |
| Godkendelse | Normal adgangskode med dit SMTP-brugernavn |

<Note>
  Brug server-hostnamet fra din mySMTP-opsaetningsmail. Kunder med dedikeret IP modtager et specifikt relay-hostname som `relayxx.mysmtp.com`. Shared IP-planer bruger `mail.mysmtp.com` og er kun tilgaengelige i Danmark.
</Note>
