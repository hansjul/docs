Du kan integrere mySMTP i enhver applikation ved hjælp af standard SMTP-biblioteker. Hvert eksempel nedenfor bruger sikker godkendelse og TLS-kryptering.

## Forbindelsesindstillinger

| Indstilling | Værdi |
| --- | --- |
| Værtsnavn | `relayxx.mysmtp.com` (dit rigtige værtsnavn står i din opsætningsmail) |
| Delt IP-værtsnavn (kun DK) | `mail.mysmtp.com` |
| Port (anbefalet) | `587` med STARTTLS |
| Alternative porte | `465` (implicit TLS), `2525` (STARTTLS fallback) |
| Godkendelse | SMTP-brugernavn og -adgangskode |

<Warning>
  Hårdkod aldrig SMTP-adgangskoder i kildekoden. Indlæs legitimationsoplysninger fra miljøvariabler, secrets managers eller krypterede konfigurationsfiler.
</Warning>
